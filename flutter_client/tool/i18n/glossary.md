# SBOX glossary — VI · EN · KO · JA · ZH (Simplified)

SBOX is a Vietnamese SaaS for shops/restaurants/small businesses: HRM (time attendance
with ZKTeco fingerprint/face devices, shifts, payroll, leave, penalties, salary
advances) and POS (selling, products, stock, tables, orders, receipts, printers).
Translate as a native product UI would read in each market. Keep these terms consistent.

## Rules

* Korean: polite UI style (합니다/하세요체 for messages, nouns for labels/buttons).
* Japanese: です/ます for messages; buttons/labels as short nouns or verbs (保存, 削除).
* Chinese: Simplified Chinese (zh-CN), concise mainland software style; use full-width
  punctuation （：，。！？） only inside Chinese sentences, keep ASCII around numbers/codes.
* Keep unchanged: {0} {1}… placeholders (same count, may be reordered), emoji, symbols
  (· • → … — ✓), numbers, URLs, e-mail, file names, ALL-CAPS codes and product/brand
  names (SBOX, SBOX POS, ZKTeco, POS, KPI, PIN, QR, OTP, VietQR, Zalo, Excel, Google…).
* The currency "đ" / "₫" / "VNĐ" stays as is (prices remain Vietnamese đồng).
* Preserve leading/trailing spaces and line breaks exactly; keep a trailing ":" "…" "*" etc.
* Vietnamese proper names of people/places stay untranslated.
